Available variables

Use variables with the # prefix:

Example:

#basePrice * #nights * #roomsCount

Example with a returning-customer adjustment:

(#basePrice * #nights * #roomsCount) - (#previousReservations * 5)
The formula is checked before it becomes active. It must use valid expression syntax, reference only the available variables, and produce a numeric result.
